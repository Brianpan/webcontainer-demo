## Conclusions

Plain-language summary:

Right now, this web page runs a whole Linux computer inside your browser. To
give that computer internet, the page had two options hidden in the web
address: one that used a fake network built inside the browser ("browser
mode"), and one that connects out to a helper program ("delegate mode"). The
browser-mode option is complicated and we do not want it anymore.

We are going to:

1. **Throw away the browser-mode plumbing.** Delete the code that starts the
   in-browser fake network.
2. **Ask the user instead of reading the web address.** When the page opens,
   a small pop-up box appears and asks: "Where is your network helper?"
   The user types something like `ws://localhost:8888`. If they type nothing
   and press start, the little Linux computer simply boots with no internet.
3. **Then start the computer.** After the pop-up is answered, the terminal
   (the black screen where you type commands) and the Linux machine load.
4. **Make it look cool.** Give the page a neon "cyberpunk" look.

User-visible outcome: open the page → a neon pop-up asks for a network
address → type it (or leave blank) → the terminal boots. Typing
`ping 1.1.1.1` reaches the internet when a real helper address was given.

Smallest useful milestone: the pop-up appears, and leaving it blank boots the
terminal with no network (proves the 2-phase load and the "empty = off" path)
even before we confirm real networking.

### Terms translated

- **delegate proxy / WebSocket URL**: the address of a small helper program
  that carries the fake computer's network traffic out to the real internet.
  Looks like `ws://localhost:8888`.
- **browser mode**: an alternative where that helper ran *inside* the browser
  tab. This is what we are deleting.
- **xterm / pty**: the black terminal screen and the plumbing that lets you
  type into the virtual computer.
- **wasm module**: the virtual computer itself, shipped as a web-runnable
  binary.

## Constraints/Dependencies

- Only the one page file `qemu/index.html` changes.
- A real network helper must be running separately to actually reach the
  internet; the page does not launch it.
